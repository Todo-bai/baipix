# Gallery

Pixel art made with Baipix, shown on the website. Each piece is a `.baipix` file listed in
[`gallery.json`](gallery.json) with its title, style and author; the site renders it to SVG at build
time with Baipix's own exporter.

Want to add yours? Open a pull request with your `.baipix` file and an entry in `gallery.json`.
Only submit original work (or public domain subjects) that you are happy to share under the
repository's MIT license.
